# 🚀 Projetos de Lógica com Vetores (C#)

Este repositório contém uma coletânea de exercícios desenvolvidos em **C#** focados no aprendizado e manipulação de **vetores (arrays)**. O objetivo é exercitar a lógica de programação, o controle de fluxo e o uso de estruturas de dados básicas.

## 📚 Conteúdo dos Exercícios

Cada exercício aborda um conceito fundamental da linguagem C#:

| Exercício | Descrição | Conceitos Aplicados |
| :--- | :--- | :--- |
| **01** | **Soma e Média** | Leitura de dados, laços de repetição (`for`) e cálculos aritméticos. |
| **02** | **Maior e Menor Valor** | Uso de valores sentinela (`MinValue`/`MaxValue`) e comparação lógica. |
| **03** | **Inversão de Ordem** | Algoritmo de troca (*swap*) com variável auxiliar e inversão de índices. |
| **04** | **Busca de Elemento** | Busca sequencial com uso de variáveis de controle (*flag* boolean). |

##💡 Aprendizados
Estes exercícios consolidaram os seguintes pontos:

**Manipulação de Índices:** Compreensão profunda de como acessar, percorrer e modificar posições em um vetor.

**Lógica de Troca:** Uso do aux para realizar trocas (swap) de valores entre posições.

**Busca e Filtragem:** Implementação de algoritmos de busca linear com encerramento antecipado (break).
